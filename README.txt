BLACKRIDGE GITHUB PAGES SITE

Files:
- index.html
- style.css

How to publish on GitHub Pages:
1. Create a new public repository on GitHub.
2. Upload index.html and style.css.
3. In repo Settings > Pages, set Source to 'Deploy from a branch'.
4. Select branch: main, folder: /root.
5. Save. Your site will go live in a minute or two.

Optional custom domain:
1. Buy a domain like blackridgefamily.com.
2. In GitHub repo Settings > Pages, add the custom domain.
3. Update your domain DNS with the records GitHub provides.
